# 📱 翌朝株価 クオンツ＆AI解析 Pro

過去1年の日足データ（RSI・MACD・ATR・ボリンジャーバンド・出来高・プライスアクション）および世界情勢マクロ（米S&P500、SOX半導体、ドル円、CME日経先物、VIX恐怖指数）をリアルタイム解析し、翌朝の寄り付き勝率・期待値エッジを算出するStreamlitアプリです。

## 🚀 主な機能
- **弱肉強食ダイナミック選抜**：候補プールから世界情勢とクオンツスコアに応じて上位20銘柄が自動で入れ替わります。
- **総合TOP5ランキング**：全セクターから本日の最強期待値銘柄をピックアップ。
- **ATRトレード目安自動算出**：予想寄付き価格、利確目標（+0.8ATR）、損切り目安（-0.5ATR）を提示。
- **スマホ完全最適化UI**：スマホの狭い画面でも美しく崩れないグリッド＆カードデザイン。
